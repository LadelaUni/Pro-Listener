# Pro-Listener
Simula a alguien que sabe escuchar.
La idea principal detrás de este proyecto era crear un espacio privado y Seguro, donde un usuario pueda desahogarse, hablar sobre su día, o expresar frustración, y recibir retroalimentación positiva, como los viejos chatbots tipo ELIZA. Quise crear una versión simple utilizando Python.
El proyecto está contenido dentro de un archive de Python (.py), y utiliza solamente sus librerías estándar, pero interactúa con el sistema de archivos para crear un registro permanente de la conversación. No quería que fuera un programa que solo imprimiera texto. Quería que se sintiera como una sesión real que puedes revisar más tarde.
